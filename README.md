# Nazwa projektu - Cusser

Szukanie świeżo założonych firm i sprawdzanie czy mają strony
internetowe/ czy ich strony internetowe są słabe i można je poprawić

## Funkcje

| Obszar          | Co robi             |
| --------------- | ------------------- |
| Strona startowa | Krótki opis funkcji |

## Tech stack

| Warstwa        | Technologie    |
| -------------- | -------------- |
| Backend        | PHP 8.3        |
| Serwer HTTP    | Nginx          |
| Konteneryzacja | Docker Compose |

## Szybki start

```bash
git clone https://github.com/LOGIN/REPOZYTORIUM.git
cd REPOZYTORIUM
docker compose up --build -d
```

Aplikacja: http://localhost:8080
